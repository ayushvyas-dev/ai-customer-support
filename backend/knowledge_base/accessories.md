
# Accessories

## Available accessories

Nexa Mobile offers the following smartphone accessories:

- Nexa 33W USB-C Power Adapter: compatible with Nexa Lite and Nexa One charging requirements.
- Nexa 67W USB-C Power Adapter: supports fast charging on Nexa One Pro.
- Nexa USB-C Cable: compatible with all Nexa smartphone models.
- Nexa Clear Case: transparent protective case with model-specific fitting.
- Nexa Armor Case: reinforced protective case for Nexa One and Nexa One Pro.
- Nexa Tempered Glass: model-specific screen protection.

Accessory availability and pricing may vary. Customers should refer to the official product listing for current details.

## Charger compatibility

Nexa smartphones use USB Type-C charging.

For the best charging experience:
- Nexa Lite supports up to 18W charging.
- Nexa One supports up to 33W charging.
- Nexa One Pro supports up to 67W charging.

Using a lower-wattage compatible charger may result in slower charging.

A higher-wattage USB-C adapter does not automatically mean the phone will charge at that adapter's maximum output. The phone controls the supported charging speed.

Avoid using damaged, uncertified, or visibly defective charging accessories.

## Case and screen protector compatibility

Phone cases and tempered glass are model-specific.

Customers should confirm their exact smartphone model before purchasing an accessory.

A Nexa One Pro case will not necessarily fit a Nexa One, even if the phones look similar.

If a customer receives an incorrectly sized accessory, collect the order number, accessory name, and smartphone model.

## Accessory troubleshooting

If an accessory is not working:

1. Check for visible damage.
2. Confirm that the accessory is compatible with the smartphone.
3. Try another compatible cable or adapter where appropriate.
4. Restart the phone if the accessory connects but is not detected.

Do not recommend using damaged charging cables or adapters.

If the accessory still does not work, collect the order number and a description of the issue.

## Missing or damaged accessories

If an accessory is missing from an order, ask the customer to check the packaging and confirm which item is missing.

If an accessory arrives damaged, request:
- Order number.
- Accessory name.
- Description of the damage.
- Photograph of the damaged item and packaging, if available.

A colleague reviews the request and confirms the available resolution.

Never independently promise a free replacement or refund.
