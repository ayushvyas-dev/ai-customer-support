
# Smartphones

## Product lineup and specifications

Nexa Mobile currently sells three smartphones designed for different everyday needs.

- Nexa One: 8GB RAM, 128GB storage, 6.5-inch AMOLED display, 50MP main camera, 5000mAh battery, 33W fast charging.
- Nexa One Pro: 12GB RAM, 256GB storage, 6.7-inch AMOLED display with 120Hz refresh rate, 50MP OIS main camera, 5000mAh battery, 67W fast charging.
- Nexa Lite: 6GB RAM, 128GB storage, 6.5-inch LCD display, 50MP main camera, 5000mAh battery, 18W charging.

All three models support 5G, dual SIM, Wi-Fi, Bluetooth, and USB Type-C charging.

Available colours depend on the model and current stock. Customers can check the product listing for the latest colour options.

## What's included in the box

Every Nexa smartphone includes:
- Smartphone handset.
- USB Type-C charging cable.
- SIM ejector tool.
- Quick start guide.
- Warranty information card.

A charging adapter and earphones are not included in the box.

Customers should use a compatible USB Type-C power adapter. Using a certified adapter from a reputable manufacturer is recommended.

## First-time setup

To set up a new Nexa smartphone:

1. Press and hold the power button until the Nexa logo appears.
2. Select the preferred language and region.
3. Connect to a Wi-Fi network.
4. Insert a SIM card if required.
5. Sign in with a Google account.
6. Follow the on-screen instructions to complete setup.

Customers transferring data from an old Android phone can use Google's device transfer feature during initial setup.

If the phone gets stuck during setup, ask the customer which screen they are seeing and whether any error message appears.

## Battery and charging issues

All Nexa smartphones use a 5000mAh battery.

If the phone charges slowly:
1. Check whether the charging cable is properly connected.
2. Try another compatible USB Type-C cable.
3. Check whether the charging adapter supports the required charging speed.
4. Restart the phone and test charging again.

Fast charging speeds depend on the compatible charging adapter, cable, battery temperature, and charging conditions.

Some reduction in charging speed near 100% is normal.

If the phone becomes unusually hot while charging, disconnect it and allow it to cool. Do not continue charging if there is swelling, smoke, a burning smell, or visible battery damage. Escalate immediately.

Battery backup depends on screen brightness, applications, network conditions, and usage patterns. Do not promise a fixed number of hours of battery life.

## Display, camera and performance issues

For display problems:
- Restart the phone.
- Check for available system updates.
- Check whether the issue occurs across all applications.
- Ask for a photo or video if the display has visible lines, flickering, or unusual spots.

For camera problems:
1. Clean the camera lens with a soft microfiber cloth.
2. Restart the camera application.
3. Check whether another application is using the camera.
4. Install available software updates.

For performance issues:
- Restart the phone.
- Check available storage.
- Close applications running in the background.
- Install available system updates.

Never ask customers to factory reset their phones before discussing the potential loss of personal data. Escalate persistent hardware-related problems.

## SIM, network and connectivity

If a customer reports network or SIM issues:

1. Check whether airplane mode is disabled.
2. Restart the phone.
3. Remove and reinsert the SIM card.
4. Check whether the SIM works in another compatible phone.
5. Check network availability with the customer's mobile operator.

For Wi-Fi issues, ask the customer to restart the router and reconnect to the network.

Nexa Mobile cannot resolve network outages, SIM deactivation, or account issues handled by mobile network operators.

Escalate persistent connectivity issues after basic troubleshooting.

## Software updates

Customers can check for updates under:

Settings > System > Software Update.

Recommend installing updates over a stable Wi-Fi connection with sufficient battery charge.

Customers should back up important data before major software updates.

Never promise a specific software update release date unless it is explicitly confirmed in the knowledge base.

## Physical damage and device faults

A device with a cracked screen, water damage, bent frame, or visible impact damage requires inspection.

Never ask customers to open the device or attempt internal repairs themselves.

For a device that will not turn on:
1. Connect it to a compatible charger.
2. Allow it to charge for approximately 30 minutes.
3. Try holding the power button for 15 seconds.

If the device still does not respond, collect the order number, model, purchase date, and a description of the issue. Escalate to a colleague.

## Information required for smartphone support

Before arranging a service request, collect:

- Order number.
- Smartphone model.
- Approximate purchase date.
- Description of the issue.
- Troubleshooting steps already attempted.

For visible physical damage, a photograph can help the support team understand the problem.

Never promise a repair, replacement, refund, or service appointment. A colleague confirms the next steps.
